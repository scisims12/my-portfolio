01 / Overview

Website development and ongoing maintenance.

Children Choice Books is the website of Children Choice Publication, an educational publishing house. It presents the publisher's books and content online.

I build, update and maintain website pages while also looking after hosting, server configuration and the underlying MySQL database. The project brings together front-end updates and day-to-day technical operations.

02 / Scope of work

One project. Several connected responsibilities.

01 — WEBSITE

Pages and interface updates

Building and maintaining pages, updating layouts and keeping the website content current, using Softr and custom HTML, CSS and JavaScript where needed.

02 — CONTENT

Book catalog and content pages

Maintaining the pages that showcase the publisher's books and educational content, and keeping front-end updates aligned with the data managed in the backend.

03 — HOSTING

Server and hosting administration

Managing the hosting environment through cPanel and WHM, handling hosting accounts, domains and day-to-day configuration, and working with Apache on Linux.

04 — DATABASE

MySQL maintenance

Working directly with MySQL and through phpMyAdmin for queries, schema updates, backups and troubleshooting the data behind the website.

03 / My role

From page updates to technical upkeep.

My responsibilities connect the visible website with the hosting and database that support it.

  • Website development: build and update pages, layouts and front-end details.
  • Content maintenance: keep book catalog and content pages up to date.
  • Hosting operations: manage hosting accounts and server configuration through cPanel and WHM.
  • Database work: write queries, update schemas and maintain backups with MySQL and phpMyAdmin.
  • Troubleshooting: investigate issues across the website, server and database.
